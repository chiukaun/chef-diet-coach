# Notion 飲食儀表板：怎麼建、怎麼更新

第一次啟動、使用者確認完「你的設定」之後，照這份建好儀表板。全部由你來建，不要叫使用者自己動手。

開始前：

- 先讀 Notion 的頁面語法說明（Notion 工具通常有一個 `notion://docs/notion-flavored-markdown-spec`，用 Notion 的 fetch 工具讀），不要猜語法
- 要建篩選過的資料庫檢視，先讀 `notion://docs/view-dsl-spec`
- 每一步都要確認工具回傳成功。失敗就重試一次，還是失敗就跟使用者說哪一步沒成功

---

## 一、建頁面

在使用者的 Notion 建一個新頁面，標題固定叫「飲食儀表板」（以後每次對話都靠這個標題找到它，不要改名）。圖示用 🍳。

頁面由上而下是這幾段：

1. 今天
2. 熱量赤字
3. 身體紀錄
4. 飲食領悟
5. 資料庫（教練在用，不用動）
6. 飲食習慣預設
7. 教練設定
8. 教練指引（你可以改）

## 二、建四個資料庫

都建在「飲食儀表板」底下。下面的欄位寫法是 Notion 工具 `create-database` 用的 SQL 格式，如果使用者的 Notion 工具格式不同，照同樣的欄位和選項建。

### 1. 飲食紀錄（每吃一樣東西就一列）

```sql
CREATE TABLE (
  "品項" TITLE,
  "日期" DATE,
  "餐次" SELECT('早餐':yellow, '乳清':orange, '午餐':green, '點心':purple, '晚餐':blue, '飲料':pink, '預留':gray),
  "大卡" NUMBER,
  "蛋白質" NUMBER,
  "時間" RICH_TEXT,
  "排序" NUMBER,
  "備註" RICH_TEXT
)
```

- 餐次「乳清」是乳清或其他蛋白飲；「飲料」只放其他飲料
- 排序：當天吃的東西照時間給 1、2、3⋯；預留的東西固定 90
- 備註：估算範圍、扣掉的盒重、看照片估的等等

### 2. 每日結算（每天一列）

```sql
CREATE TABLE (
  "日子" TITLE,
  "日期" DATE,
  "週次" NUMBER,
  "赤字目標" NUMBER,
  "消耗" NUMBER,
  "攝取" NUMBER,
  "赤字" NUMBER,
  "狀態" SELECT('達標':green, '有赤字未達標':orange, '吃超過':red, '消耗未回報':gray),
  "消耗來源" SELECT('手錶':blue, '估算':gray)
)
```

- 日子寫成「12/3｜第1週目標100」
- 赤字＝消耗－攝取

### 3. 身體紀錄

```sql
CREATE TABLE (
  "紀錄" TITLE,
  "日期" DATE,
  "腰圍" NUMBER,
  "體重" NUMBER,
  "備註" RICH_TEXT
)
```

- 同一天量好幾次就取平均
- 沒量的欄位留空

### 4. 常見品項（吃過、有標示的東西存起來，下次直接查）

```sql
CREATE TABLE (
  "品項" TITLE,
  "份量" RICH_TEXT,
  "大卡" NUMBER,
  "蛋白質" NUMBER,
  "來源" SELECT('包裝標示':green, '估算':gray),
  "備註" RICH_TEXT
)
```

- 品項寫品牌＋品名，例如「義美無糖豆漿 450ml」
- 使用者給過包裝標示、或同一樣東西吃第二次，就存進來

把四個資料庫的 data source ID（`collection://…`）都記進「教練設定」。

## 三、頁面內容

### 1. 今天

```
## 今天
（一行灰字，見下面）
（熱量環形圖）
（蛋白質環形圖）
（今天吃了什麼：飲食紀錄的檢視）
```

- 環形圖：用 `scripts/ring_url.py` 組網址，用圖片區塊放進頁面（`![](網址)`），Notion 會自己去網址抓圖，不用上傳檔案。剛建好時用「什麼都還沒吃」的數字畫一次
- 今天吃了什麼：在這裡建一個飲食紀錄的表格檢視，篩選「日期＝今天」，依「排序」由小到大，只顯示品項、餐次、大卡、蛋白質、時間。篩選「今天」的語法照 view-dsl-spec；做不到相對日期，就改成依日期由新到舊排序

灰字（用灰色文字）：

- 進行中：還能吃 X 大卡（已扣預留 Y）／蛋白質還差 Z 克（已扣預留 W）
- 預留的東西已經吃了：拿掉「已扣預留」
- 已吃的蛋白質達標：蛋白質那邊改「蛋白質已吃 Z 克（已達標）」
- 已吃未達標，但加上預留會達標：改「蛋白質已吃 Z 克（含預留已達標）」
- 熱量超過：熱量那邊改「超過 X 大卡」
- 已結算：「當日結算：消耗 X 大卡，攝取 Y 大卡，赤字 Z 大卡」

### 2. 熱量赤字

```
## 熱量赤字
（callout：赤字階梯，每週一行，例如「第1週 12/1–12/7：每天 100」，目前這週標出來）
（callout：本週，已記幾天、達標幾天、平均赤字）
（赤字折線圖）
（一行灰字：綠＝達標，橘＝有赤字未達標，紅＝吃超過；特殊日子也寫在這）
（每日結算的表格檢視，依日期由新到舊）
```

- 折線圖用 `scripts/deficit_url.py`。還沒有結算過的日子時，先放一行灰字「第一天結算後這裡會出現折線圖」，結算第一天再換成圖
- 目標是增肌或維持的人，這一段叫「熱量差額」，不放階梯，折線圖不用

### 3. 身體紀錄

```
## 身體紀錄
（callout：最新腰圍、體重；每週平均，跟上週、跟第一週比）
（腰圍折線圖）
（一行灰字：綠點是每天早上的腰圍，紫線是每週平均，週一到週日，每週日結算）
（身體紀錄的表格檢視，依日期由新到舊）
```

- 折線圖用 `scripts/body_url.py`。只有一筆資料時先不放圖，第二筆再放
- 每週日把這週的日子在第 4 欄填上週次，圖上就會多一段紫色的週平均線

### 4. 飲食領悟

```
## 飲食領悟
（黃色 callout，一筆一行「M/D　發生什麼 → 感受或領悟」，最新的在最上面）
```

- 使用者說要記一個領悟或反思，或回答了結算後的覆盤問題，就照他的話寫進去，不加你的評論

### 5. 資料庫（教練在用，不用動）

四個資料庫本體放這裡。

### 6. 飲食習慣預設

```
## 飲食習慣預設
每天固定吃的（每天自動算進去）：
- 品項、份量、大卡、蛋白質、主要營養（例如魚油 2 粒：Omega-3；綜合維生素 1 錠：大部分維生素）

每天預留的（還沒吃，但先從「還能吃」扣掉）：
- 品項、大概幾點、大卡、蛋白質

靠食物補的：纖維、鉀、鎂、鈣（一般補充品放很少）
```

### 7. 教練設定

這一段是教練的記憶。每次新對話都要讀，內容要完整到「別的對話看了就能接手」：

```
## 教練設定
開始日期：2026-12-01（第 1 週從這天算起，每 7 天一週）
時區：Asia/Taipei

身體：身高、體重、年齡、性別、體脂、腰圍
健康注意：（看醫生的病、藥、過敏、不吃的東西；沒有就寫沒有）
目標：（想變成什麼樣子、數字、期限、為什麼）

每日消耗：約 X 大卡（手錶最近 7 天平均／公式估算：基礎代謝 Y × 活動量 Z）
最終每日赤字：X 大卡
赤字階梯：第1週 100、第2週 200⋯⋯到 X 就維持
每日熱量目標：本週 X 大卡（＝每日消耗－本週赤字目標）
每日蛋白質目標：X 克（每公斤 Y 克 × Z 公斤）

消耗怎麼來：手錶（品牌）／估算
行程從哪裡讀：Notion「週計畫」頁面／Google 日曆／每天早上問
生活習慣重點：起床、第一餐、最後一餐、運動日、外食比例、會不會煮、廚具、容易失控的時段、喝酒
常去的地方：（全聯、7-11、公司附近的自助餐⋯⋯）

資料庫：
- 飲食紀錄：collection://…
- 每日結算：collection://…
- 身體紀錄：collection://…
- 常見品項：collection://…
```

數字有變（每週換階梯、重算消耗、體重變了）就更新這一段。

### 8. 教練指引（你可以改）

```
## 教練指引（你可以改）
這裡寫你對教練的要求，教練每次都照最新版。例如：
- 回覆再短一點
- 不要推薦牛肉
- 晚上 9 點以後不要建議吃東西
```

建好時先放上面這幾行範例，告訴使用者可以直接在 Notion 改。

## 四、更新圖表的方法

- 圖片區塊的網址就是圖。要更新圖，就把頁面上舊的整串網址換成新的整串網址
- 熱量圖和蛋白質圖的網址有很多相同的片段，局部替換很容易換錯。一律整串網址替換，而且替換前確認舊網址在頁面上只出現一次
- QuickChart 要能被 Notion 連到（`https://quickchart.io`），不需要帳號
- 圖是深色底，適合手機深色模式
